# Charter Rendering Boundary

Charter Markdown is an engine-owned deterministic review projection of immutable candidate or selected canonical YAML.

Treat `CHARTER_INPUTS.yaml` as the source of truth. This applies to caller intent only; engine-owned immutable lineage and selected canonical truth remain authoritative.

Do not synthesize, edit, persist, or promote Charter Markdown. Do not treat a rendered view as canonical input. Use the native author command to create a candidate, the native approval command for human authority, the promotion command for atomic selection, and `handbook author charter --validate` to inspect selected truth.
