## Owner and host boundaries

Engine owns Charter/posture, operating definitions/envelopes, exact request
non-expansion and authorization issuance/currentness. Contracts owns intrinsic
definition conformance, applicable qualification, complete direct requirements,
Evaluation Coordination, evidence admission/closure and semantic truth. Dock
owns exact package/request/execution/observation provenance. SDK composes these
owners and exposes typed consumer results; it cannot select a missing rule,
approve a scope expansion, or reconstruct Engine decisions. No owner depends
back on SDK or Substrate.

The minimum host interface is caller-carried typed requests/results: exact
project/root, current basis, intended operation and reach, original instruction
and assurance provenance, and exact refusal/decision-request context. A later
resolution submission binds the original unresolved request, proposed choice,
decision source and prior delegated authority; the responsible owner accepts,
denies or requires clarification. Delivery/timeout cannot grant permission.
Initial decisions remain human decisions. A configured role, more context or a
host session token is insufficient native authority. A project-level agent can
resolve only choices the prior terms actually delegate; human escalation is for
reserved decisions, unresolved material ambiguity or missing authority with no
authorized resolution.

routed agent escalation or claim that a project agent has resolved anything.
The full slice's minimal request/decision submission can operate with a caller
or manually delivered project-agent response. Automatic discovery/delivery,
