# HCM-4.1 planning dependency-order exception

**Decision ID:** `HCM-4.1-PLANNING-PHASE-3-OPEN-EXCEPTION-01`

## Decision

The operator authorizes one additive sequencing exception: planning/control-pack
work for HCM-4.1 may proceed while Phase 3 remains open. The narrow reason is
that the unresolved HCM-3.6 private posture-transition reachability seam needs
the Phase-4 SDK/ordinary-consumer boundary before a genuine production adoption
path can be selected.

## Preserved limits

- Phase 3 remains open. HCM-3.6, strict-Clippy
  `HCM3EXIT-P2-CLIPPY-001`, HCM-3.5 Packet 5, and HCM-3.5 Packet 6 are not
  completed, waived, baselined, or accepted as debt.
- The exception authorizes HCM-4.1 planning only. It does not authorize
  HCM-4.1 implementation, HCM-4.2+, Phase 5, Phase 6, release, publication,
  push, a new dependency, a public API, or a transport change.
- HCM-4.1 planning must name a real SDK/ordinary-consumer posture ingress with
  recommendation, policy, approval, canonical-head, reassessment, and
  compare-and-write bindings. It must reject promotion, recovery, startup,
  tests, unrelated services, and legacy compiler/CLI wiring as synthetic
  reachability.
- Later Phase-3 closure must consume actual Phase-4 production adoption proof
  and independently rerun strict Clippy, regressions, causal review, and every
  Phase-3 exit gate. Planning evidence alone is insufficient.
